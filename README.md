# Control mensual DLV

App web local para controlar disputas Uber por local y por semana.

## Uso

Abre `index.html` en el navegador.

La app crea automaticamente las semanas del mes actual usando la fecha del sistema. El corte semanal sigue el formato de la planilla original: la semana termina el viernes.

## Funciones

- Agregar locales.
- Crear o eliminar semanas.
- Editar metricas por semana.
- Calcular automaticamente `Sin disputas`.
- Marcar cumplimiento cuando `Sin disputas` es menor o igual al limite configurado.
- Ver resumen mensual acumulado con totales y porcentajes.
- Exportar respaldo JSON.
- Importar respaldo JSON.
- Exportar resumen mensual en formato HTML bonito e imprimible.
